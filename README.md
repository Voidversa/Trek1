Найди команду

Хакатон 1.0 · Трек 1: «Найди команду»

Назначение и возможности

Приложение помогает автору проекта собрать команду, а желающему присоединиться найти подходящую вакансию и подать заявку. Результат работы — сформированный состав проекта и понятный статус каждой заявки.

Реализованы все обязательные функции Н01–Н10 задания трека и правила раздела 3 (проверяются на сервере):

регистрация, вход и выход; профиль с описанием, навыками и интересами (Н01);
создание проекта с вакансиями и публикация при наличии хотя бы одной вакансии с положительным числом мест (Н02, Н03);
каталог с поиском по названию и описанию, фильтрами по категории, навыку и статусу набора, сортировкой по дате (Н04);
страница проекта: описание, вакансии со свободными местами, автор, состав (Н05);
подача заявки с сопроводительным сообщением и её обработка автором: принять или отклонить; кандидат может отозвать ожидающую заявку (Н06, Н07);
личные разделы: свои проекты, входящие заявки автора с фильтром по статусу, свои заявки кандидата (Н08);
редактирование проекта и вакансий с защитой от потери данных (Н09);
закрытие и повторное открытие набора (Н10).

Одна учётная запись может быть автором в одном проекте и кандидатом в другом: роль определяется относительно конкретного проекта.

Технологии и устройство
Клиент: одностраничный интерфейс на чистом HTML, CSS и JavaScript (файл index.html), маршрутизация по #.
Сервер: Python, только стандартная библиотека (http.server), JSON API по адресу /api/... (файл app.py).
База данных: SQLite, файл data.db в папке проекта (или путь из переменной DB_PATH). Отдельный запуск базы не нужен.
Внешние зависимости и интернет: не требуются.
Схема данных: константа SCHEMA в файле app.py; описание ниже.
Роли и проверка прав: отдельных типов учётных записей нет. Роль «автор» определяется сравнением projects.author_id с текущим пользователем в каждом запросе на сервере; интерфейс только скрывает недоступные кнопки. Пароли хранятся как соль и хеш PBKDF2-SHA256; сессия передаётся в cookie sid (HttpOnly, SameSite=Lax).
Схема данных
users(id, email*, pw, name, bio, skills, interests)      sessions(token, user_id)
projects(id, author_id→users, title, description, goal, category, published, open, created_at)
vacancies(id, project_id→projects, role, skills, description, seats>=1)
applications(id, user_id, project_id, vacancy_id, message, status, created_at)
   уникальный индекс (user_id, project_id) WHERE status='pending'   -- одна активная заявка
members(id, project_id, vacancy_id, user_id, application_id*, UNIQUE(project_id, user_id))

Свободные места не хранятся счётчиком: свободно = seats − count(members), поэтому рассинхронизации нет.

Как обеспечены правила
Принятие заявки идёт в транзакции BEGIN IMMEDIATE: проверка места, добавление участника и смена статуса заявки выполняются атомарно, параллельные принятия на последнее место выстраиваются в очередь.
Одна ожидающая заявка на проект гарантируется и проверкой в коде, и частичным уникальным индексом базы. Повторный запрос возвращает 409.
Сообщения кандидатов отдают только /api/projects/:id/applications (автору проекта) и /api/my/applications (самому кандидату).
Обязательные поля, длины, число мест (целое, не меньше 1) и категория проверяются на сервере.
Требования для запуска
Любая ОС, на которой работает Python.
Python 3.9 или новее (проверено на 3.12). Команда может называться python или python3.
Docker и другие программы не нужны. Интернет не нужен.
Установка и настройка
Получите исходники и перейдите на указанный выше финальный коммит или тег.
Установка зависимостей не требуется: используется только стандартная библиотека Python.
Файл конфигурации не нужен. Необязательные переменные окружения: PORT (порт, по умолчанию 8000) и DB_PATH (путь к файлу базы).
Подготовьте базу с демонстрационными данными (создаёт файл data.db с нуля):
   python app.py reset

Команда создаёт таблицы, четыре тестовых аккаунта и демонстрационные записи.

Запуск приложения

Из папки проекта:

python app.py

Адрес приложения: http://localhost:8000

Другой порт:

Linux и macOS: PORT=9000 python app.py
Windows (PowerShell): $env:PORT=9000; python app.py

Остановка: Ctrl+C в терминале с сервером. Повторный запуск: python app.py; данные в data.db сохраняются.
